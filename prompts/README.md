# Prompts

A collection of random prompts that can be helpful. Mostly for inspiration when
writing new prompts and working on skills and agents.

If a prompt is needed multiple times, it should be baked into a skill or an
agent.

## Simple phased approach

First prompt:

* Detail the project
* Set ground rules

Really spend some time building a good prompt with a lot of details and write it
all down before you run the model against it. This also allows you to run the
same prompt against different models.


## CRAFT workflow

Tell the model you will follow the CRAFT workflow and it should work through the
phases one at a time and not skip any step.

* Context - Give context on the domain, including the problem to solve, examples, and documents.
    * You are in context mode. Only reply with `ok` for each resource I give you until 
    I tell you to proceed with our discussion and next steps.
* Riff — Discuss major issues or approaches with the model.
* Ask — Answer clarifying questions generated by the model.
* Frame — Request and iterate on a written plan for the task.
* Task — Work with the model as it implements the plan.
