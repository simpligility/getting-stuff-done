# Skills

A number of skills to use to complete repetitive tasks or help with other
skills and tasks.

Each skill is a directory containing a `SKILL.md` file, along with any scripts,
references, and assets it needs.

The repository README lists and explains them:

- [Skill catalog](../README.md#skill-catalog) for the complete list of skills
  and what each one does
- [Installing individual skills](../README.md#installing-individual-skills) for
  installation instructions
