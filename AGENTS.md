# AI assistant instructions

Global preferences for AI coding assistants (Claude Code, Codex, Gemini, etc.).
This file is the canonical source; tool-specific paths (`~/.claude/CLAUDE.md`,
`~/.codex/AGENTS.md`, `~/.gemini/GEMINI.md`) are symlinks to it.

## Commit messages

- Keep the subject line under ~70 characters.
- Check prior commits in the repository to find what style is used and then
  follow the style. Typical choices are:
  - [conventional commits](https://www.conventionalcommits.org/) style with
    `docs(scope): ...`, `fix(scope): ...`
  - [Chris Beams' guidelines](https://chris.beams.io/git-commit), as used in
    the [Trino and Airlift projects](https://trino.io/development/process#pull-request-and-commit-guidelines)
- Wrap the commit body at 80 characters per line. Exceptions are acceptable
  when a single token cannot be broken — for example a long URL, a long file
  path, or quoted output that must remain on one line.
- When a commit covers multiple distinct changes, write the body as a bulleted
  list rather than a single long paragraph. Each bullet should describe one
  change.
- Use `Assisted-by:` as the attribution trailer with the tool vendor's
  no-reply email address. Do **not** use `Co-Authored-By:` — frame the AI as
  an assistant, not a co-author. For example, when the commit is generated by
  Claude (Anthropic): `Assisted-by: Claude Opus 4.7 <noreply@anthropic.com>`.
